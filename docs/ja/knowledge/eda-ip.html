EDA と IP：チップ設計の料金所

チップが存在する前に、それはツールで設計され、ライセンスされたブロックから組み立てられる。EDA と IP は小さな市場でありながら、バリューチェーン全体を大きく左右する。

現代のシステムオンチップは数十億個のトランジスタと、数十の再利用ブロックを含んでいます。そのほとんどはゼロから設計されたものではありません。それを可能にしているのが二つの層です。EDA ソフトウェアは設計意図を製造可能な幾何形状に変換し、IP は検証済みの回路ブロックをあらかじめ供給します。

二つのビジネスモデル

  • EDA：ライセンス供与が中心で、通常は複数年契約に基づく期間ベースのサブスクリプション。収益は継続的で見通しがよく、更新時の粗利益率は非常に高い。
  • IP：設計ごとにライセンスし、その後は出荷チップ1個あたりのロイヤルティを得る。ロイヤルティは初期ライセンスから1〜3年遅れて計上されるため、IP の収益は最終市場の出荷量に連動する。

最大手3社（Synopsys、Cadence、Siemens EDA）で市場の過半を占めます。プロセッサ IP は Arm が圧倒し、インターフェース IP とメモリ IP は複数の専門企業に分かれています。

乗り換えが難しい理由

EDA は単体で買う製品ではありません。ファウンドリが提供するプロセス設計キット（PDK）、検証サインオフ、エミュレーション、実装、テストといったフローに組み込まれています。ツールを替えることは、フロー全体の再認定、エンジニアの再教育、そしてテープアウトのリスクを意味します。価格だけで顧客が乗り換えることはほとんどありません。

したがって参入障壁はワークフローの囲い込みと人材です。大学は支配的なツールを教え、経験を積んだエンジニアはその習熟を持ったまま企業間を移ります。

AI が変えるもの

機械学習は配置配線、設計空間の探索、検証カバレッジ、リソグラフィ最適化へ適用されつつあります。その効果はエンジニア1人あたりの生産性向上であり、ツールチェーンの価値を置き換えるのではなく、むしろ高めます。単機能ツールでは新興企業の余地が生まれますが、フロー全体ではまだその段階ではありません。

中国の視点

中国の国内 EDA 企業は、ローカライズ政策に支えられて、単機能ツールと成熟ノード向けフローで急速に成長しました。難しい部分として残るのは、先端ノードのフルフローと、最先端設計に必要な IP です。それゆえ EDA への輸出管理は影響が不釣り合いに大きくなります。制約されるのは一つの製品ではなく、設計そのものの能力だからです。

観察指標

  • サブスクリプションの未消化契約残高と更新率。
  • 最終市場のチップ出荷量の代理指標としてのロイヤルティ収益。
  • 3D-IC とチップレット設計ツールの採用状況。
  • 中国売上へのエクスポージャーと輸出管理の変更。
  • 研究開発費率。大手では売上高の30〜40%が標準的です。
