# 方法论：因子、分数与边界

版本 3.0.0 · 生效 2026-11-11 · 对应站内 `/methodology.html`

本文件定义站内每个数字的计算方法。任何方法变更都必须同时更新本文件、站内方法页、`CHANGELOG.md` 与版本号。

---

## 1. 研究问题

方法只回答三个问题：

1. **这个环节现在处于什么状态？**（市场状态读数）
2. **哪些公司值得优先阅读？**（研究优先级）
3. **我的判断依赖的数据是否完整？**（数据完整度）

不回答：未来收益、目标价、买卖时点或仓位。

## 2. 样本与分类

- **样本**：`data/universe.csv` 中的 175 家上市公司。
- **一公司一上市地**：优先主上市地；同一公司不在多个市场重复计数（例如 SMIC 只保留 A 股 688981，华虹只保留港股 1347）。
- **环节**：按主要收入来源把每家公司归入 8 个环节之一；这属于编辑判断，PR 中必须说明依据。
- **角色**：fabless / foundry / idm / memory / equipment / materials / osat / module / eda_ip。
- **地区**：总部地区，13 个取值之一。**上市地**：上市市场，7 个取值之一；两者可能不同（例如 NXP 总部在荷兰、上市在美国）。
- **产品标签**：来自 `taxonomy.json` 中 70 个标签的受控词表，用于筛选与公司页展示。
- **公司元数据**：`founded`（年份）与 `fiscal_year_end`（月份）是描述性字段，不参与任何因子。

新增或剔除公司必须满足：已上市、收入主要来自半导体、有可靠的行情来源，并且能填补缺失的环节或地区，或是关键龙头。变更记录在 `CHANGELOG.md`。

## 3. 数据字段

| 字段 | 定义 | 单位 | 缺失处理 |
| --- | --- | --- | --- |
| `price` | 最新可得收盘价（延时行情） | 本币 | 显示 `—`；不参与价格类因子 |
| `change_pct` | 最近交易日涨跌幅 | % | 同上 |
| `ret_30d` | 最近 30 个**交易日**涨跌幅 | % | 同上 |
| `ret_ytd` | 年初至今涨跌幅 | % | 不参与评分 |
| `market_cap` | 总市值（本币） | 本币 | 不参与规模因子 |
| `market_cap_usd` | 市值 × 汇率 | USD | 不参与规模因子 |
| `pe` | 静态市盈率（最近年度 EPS） | 倍 | ≤ 0 或缺失 → 估值因子缺失 |
| `pb` | 市净率 | 倍 | 缺失不影响其他因子 |
| `roe` | 净资产收益率 | % | 缺失 → 质量因子缺失 |
| `turnover` | 换手率 | % | 仅展示，不参与评分 |
| `high_52w` / `low_52w` | 最近 250 个交易日最高 / 最低价 | 本币 | 缺失 → 区间位置缺失 |
| `coverage` | 8 个字段的覆盖比例 | 0–1 | 见 §6 |

> 52 周区间按 250 个交易日近似，不一定等于自然年。

## 4. 因子定义

所有因子先在**同环节**内做百分位归一化到 0–100；环节样本少于 8 家时退回全样本。百分位采用中位秩（并列取平均秩）。

### 4.1 质量

```text
quality = percentile_rank(ROE, peer_group)
```

ROE 越高，质量分越高。缺少 ROE 时该因子缺失。

### 4.2 估值

```text
valuation = percentile_rank(-PE, peers_with_positive_PE)   # PE > 0
valuation = missing                                        # PE ≤ 0 或缺失
```

PE 越低，估值分越高。亏损公司不会得到“便宜”的错觉；它们的估值因子直接视为缺失。

### 4.3 动能

```text
momentum = 0.6 × percentile_rank(ret_30d, peers)
         + 0.4 × percentile_rank(range_position, peers)

range_position = (price - low_52w) / (high_52w - low_52w)  ∈ [0,1]
```

一个分量缺失时，按剩余权重重新归一；两个都缺失时该因子缺失。

### 4.4 规模

```text
size = percentile_rank(log10(market_cap_usd), peers)
```

规模是流动性与抗风险能力的代理，不是质量高低的度量。

### 4.5 研究优先级

```text
priority = 100 × Σ(w_i × factor_i) / Σ(w_i)      # sum over available factors only
w = {quality: 0.30, valuation: 0.25, momentum: 0.25, size: 0.20}
```

- 缺失因子不补 50 分，而是对剩余权重**重新归一**，避免中性值造成扭曲。
- `factor_coverage = Σ available weights / 1.0`，用于提示这个分数值得多少信任。
- 结果四舍五入为整数，并限制在 0–100。

## 5. 风险标签

| 标签 | 触发条件 | 含义 |
| --- | --- | --- |
| `loss` | `pe ≤ 0` | 最近财年亏损，估值不适用 |
| `rich` | 估值分 ≥ 80 | 相对同环节偏贵 |
| `small` | 市值 < 20 亿美元 | 规模与流动性偏弱 |
| `sharp` | `abs(ret_30d)` ≥ 25% | 近 30 日价格波动大 |
| `stale` | 快照超过 48 小时 | 数据可能过期 |

`risk_level`：无有效标签 = low；1–2 个 = medium；3 个及以上 = high。`stale` 单独展示，不计入风险等级。

## 6. 数据完整度

8 个字段为 `price`、`change_1d`、`ret_30d`、`market_cap_usd`、`pe`、`pb`、`roe` 与 `range`。

```text
coverage = available fields / 8
≥ 0.875 → high      (7–8 fields)
≥ 0.625 → medium    (5–6 fields)
< 0.625 → low       (4 or fewer fields)
```

完整度衡量字段是否**存在**，而不是数据是否准确。

## 7. 市场状态

对全部有 `ret_30d` 的公司：

```text
breadth    = advancing companies / valid companies
median     = median(ret_30d)
dispersion = P75(ret_30d) - P25(ret_30d)
```

判定：

| 条件 | 状态 |
| --- | --- |
| breadth ≥ 0.60 且 median > 2% | 扩张 |
| breadth ≤ 0.40 且 median < −2% | 收缩 |
| 其他 | 中性 |

领先 / 落后环节指样本至少 3 家、中位涨幅最高 / 最低的环节。市场状态描述当前结构，不预测方向。

## 8. 研究清单

| 清单 | 规则 | 排序 |
| --- | --- | --- |
| 质量优先 | `quality ≥ 70` 且 `valuation ≥ 50` | priority 降序 |
| 估值回落 | `valuation ≥ 70` 且 `quality ≥ 50` | valuation 降序 |
| 动能领先 | `momentum ≥ 80` 且 `ret_30d > 0` | momentum 降序 |

每个清单最多 8 家公司，且只包含有价格的公司。

## 9. 解读指南

- **分数是相对的**：同一家公司在另一个环节或另一个日期，分数可能不同。
- **高分不等于好公司**：它可能只是便宜、由动能驱动，或被归入样本较少的环节。
- **低分不等于差公司**：它可能处于周期底部、数据缺失，或估值偏高但质量更强。
- **不要跨环节比较分数**：归一化在环节内完成。
- **结合完整度阅读**：完整度低的分数只能作为参考。

## 10. 已知局限

1. 行情为延时或收盘价，不含盘口与盘中信号。
2. 静态 PE 对高增长公司不友好；亏损公司没有估值因子。
3. 缺少营收增速、订单、产能利用率与库存数据，质量因子只能依赖 ROE。
4. 52 周区间用 250 个交易日近似。
5. 汇率每日更新，跨币种比较存在日度误差。
6. 分类包含编辑判断；业务变化需要季度复核。
7. 样本偏向大型上市公司，因此存在幸存者偏差。

## 11. 变更控制

1. 修改公式或阈值 → 更新本文件 + 站内方法页 + `CHANGELOG.md`，并提升主版本号。
2. 新增因子 → 先做离线对比，记录对研究清单的影响，再合并。
3. 修改样本或分类 → 在 PR 中列出公司、原因与受影响的页面。
4. 每次构建都会重新计算分数，不保留历史分数；如需回测，使用 `data/snapshots/` 中的历史快照。
