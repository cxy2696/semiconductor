# 路线图

版本 2.0 · 2026-11-11

原则：先保证**可核查**与**可维护**，再扩展覆盖与功能。每项都写清验收标准，避免“看起来做了”。

## 近期（1–3 个月）

### 1. 第二行情源与交叉校验

**问题**：单一供应商（东方财富），字段语义或可用性变化时缺少对照。

**方案**：接入一个独立源（如交易所官方日线或 Stooq），对价格与涨跌幅做容差比对，不一致时标记 `source_conflict`。

**验收**：≥ 90% 标的有两个来源；冲突率 < 2%；页面显示冲突标记；测试覆盖比对逻辑。

### 2. 基本面字段扩展

**问题**：质量因子只有 ROE，缺少增长与现金流。

**方案**：增加营收增速、毛利率、经营现金流/净利润、净负债/EBITDA（若来源可得），引入“增长”因子并重新分配权重。

**验收**：新因子有独立定义与缺失处理；方法页更新；离线对比显示清单变化 < 30%。

### 3. 公司页结构化数据

**问题**：公司页缺少 `Organization` / `Corporation` JSON-LD，搜索曝光弱。

**方案**：为公司页生成 JSON-LD，包含名称、代码、总部、网址、所属行业。

**验收**：Rich Results 测试通过；不引入无效字段。

### 4. 内容审校

**问题**：英 / 日版本由同一位作者完成，缺少母语审校。

**方案**：邀请 1–2 位审校者，按术语表统一译名，记录审校日期。

**验收**：9 篇 × 2 语言全部审校；术语表与正文一致；CHANGELOG 记录。

## 中期（3–6 个月）

### 5. 产业链图谱交互

**方案**：在产业链页增加“按地区 / 角色”高亮与公司气泡图；保持无 JS 可读的降级视图。

**验收**：键盘可操作；SSR 内容完整；移动端可用。

### 6. 季度回顾报告（自动草稿）

**方案**：基于历史快照生成季度结构变化摘要（环节市值占比、宽度、领先/落后），人工编辑后发布为知识页。

**验收**：脚本可复现；草稿含数据与图表；人工审核流程明确。

### 7. 事件日历

**方案**：维护财报日、行业展会、政策生效日（手工 JSON），在首页与公司页展示。

**验收**：日期可核查；过期自动隐藏；三语标签。

### 8. 数据质量面板

**方案**：新增 `/status.html`，展示覆盖率、过期标的、解析失败、来源状态与最近 30 次构建。

**验收**：不暴露敏感信息；可作为运维入口。

## 长期（6–12 个月）

### 9. 多源新闻与主题聚类

**方案**：扩展中文 / 日文媒体源，按环节与公司做主题聚类，提供“本周环节动态”。

**验收**：来源可配置；去重与相关性评估；版权合规。

### 10. 历史序列与周期定位

**方案**：保留更长历史（或按周聚合），计算估值分位、宽度历史、环节轮动。

**验收**：数据量可控（< 20MB）；页面性能不退化；方法可解释。

### 11. iOS 客户端升级

**方案**：从 `latest_data.json` 迁移到 `/api/snapshot.{lang}.json`，支持三语与全球公司。

**验收**：旧版仍可解码；新版支持语言切换；TestFlight 验证。

### 12. 社区贡献流程

**方案**：Issue 模板（数据纠错 / 内容建议 / 方法讨论）、PR 模板、贡献者名单。

**验收**：模板可用；CI 对 PR 自动校验；合并周期 < 7 天。

## 不做的方向

- 实时 Level-2 行情、交易接口、仓位建议。
- 付费墙、广告、用户追踪。
- 用 LLM 自动生成未经审核的投资结论。
- 为追求覆盖而加入无法验证数据的公司。

## 优先级规则

按以下顺序取任务：

1. 影响数据可信度（来源、契约、校验）
2. 影响可维护性（文档、测试、CI）
3. 影响理解深度（内容、方法、可视化）
4. 影响覆盖广度（新公司、新市场）

新功能必须回答：**它让读者更清楚，还是只是更多？**
