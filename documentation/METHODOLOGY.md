# 方法论：因子、分数与边界

版本 2.0.0 · 生效 2026-11-11 · 对应站内 `/methodology.html`

本文件定义站内所有数字的计算方法。任何方法变更都必须同时更新本文件、站内方法页、`CHANGELOG.md` 与版本号。

---

## 1. 研究问题

方法只回答三个问题：

1. **这个环节现在处于什么状态？**（市场状态读数）
2. **哪些公司值得优先阅读？**（研究优先级）
3. **我的判断依赖的数据是否完整？**（数据完整度）

不回答：未来收益、目标价、买卖时点、仓位。

## 2. 样本与分类

- **样本**：`data/universe.csv` 中的 124 家上市公司。
- **一公司一上市地**：优先主上市地；同一公司不在多个市场重复计数（如 SMIC 只保留 A 股 688981，华虹保留港股 1347）。
- **环节（stage）**：按主要收入来源归入 8 类之一，由编辑判断，需在 PR 中给出依据。
- **角色（role）**：fabless / foundry / idm / memory / equipment / materials / osat / module / eda_ip。
- **地区（country）**：总部所在国家/地区；**上市地（market）** 单独记录，两者可能不同（如 NXP 总部荷兰、上市美国）。
- **产品标签（products）**：来自 `taxonomy.json` 的受控词表，用于筛选与公司页展示。

新增或剔除公司需满足：上市、收入以半导体为主、可获取可靠行情、覆盖一个此前缺失的环节或地区。变更记录在 `CHANGELOG.md`。

## 3. 数据字段

| 字段 | 定义 | 单位 | 缺失处理 |
| --- | --- | --- | --- |
| `price` | 最新可得收盘价（延时行情） | 本币 | 显示 `—`，不参与价格类因子 |
| `change_pct` | 最近交易日涨跌幅 | % | 同上 |
| `ret_30d` | 最近 30 个**交易日**收盘价涨跌幅 | % | 同上 |
| `ret_ytd` | 年初至今涨跌幅 | % | 不参与评分 |
| `market_cap` | 总市值（本币） | 本币 | 缺失则不参与规模因子 |
| `market_cap_usd` | 总市值 × 汇率 | USD | 缺失则不参与规模因子 |
| `pe` | 静态市盈率（最近年度 EPS） | 倍 | ≤ 0 或缺失 → 估值因子缺失 |
| `pb` | 市净率 | 倍 | 缺失不影响其他因子 |
| `roe` | 净资产收益率 | % | 缺失 → 质量因子缺失 |
| `turnover` | 换手率 | % | 仅展示，不参与评分 |
| `high_52w` / `low_52w` | 最近 250 个交易日最高 / 最低价 | 本币 | 缺失 → 区间位置缺失 |
| `coverage` | 8 个字段的覆盖比例 | 0–1 | 见 §6 |

> 52 周区间按 250 个交易日近似，不一定等于自然年。

## 4. 因子定义

所有因子先在**同环节**内做百分位归一化到 0–100；环节样本少于 8 家时退回全样本。百分位采用中位秩（ties 取平均）。

### 4.1 质量 Quality

```text
quality = percentile_rank(ROE, peer_group)
```

ROE 越高，质量分越高。缺少 ROE 时为缺失。

### 4.2 估值 Valuation

```text
valuation = percentile_rank(-PE, peers_with_positive_PE)   # PE > 0
valuation = missing                                        # PE ≤ 0 或缺失
```

PE 越低，估值分越高。亏损公司不给“便宜”的错觉，直接视为缺失。

### 4.3 动能 Momentum

```text
momentum = 0.6 × percentile_rank(ret_30d, peers)
         + 0.4 × percentile_rank(range_position, peers)

range_position = (price - low_52w) / (high_52w - low_52w)  ∈ [0,1]
```

两个分量缺一时，按剩余权重归一；都缺则缺失。

### 4.4 规模 Size

```text
size = percentile_rank(log10(market_cap_usd), peers)
```

规模作为流动性与抗风险能力的代理，不代表“越好”。

### 4.5 研究优先级 Priority

```text
priority = 100 × Σ(w_i × factor_i) / Σ(w_i)      # 仅对可用因子求和
w = {quality: 0.30, valuation: 0.25, momentum: 0.25, size: 0.20}
```

- 缺失因子不补 50 分，而是**按剩余权重重新归一**，避免中性值扭曲排序。
- `factor_coverage = Σ可用权重 / 1.0`，用于提示分数可信度。
- 结果四舍五入为整数，限制在 0–100。

## 5. 风险标签

| 标签 | 触发条件 | 含义 |
| --- | --- | --- |
| `loss` | `pe ≤ 0` | 最近年度亏损，估值因子不适用 |
| `rich` | 估值分 ≥ 80 | 相对同环节偏贵 |
| `small` | 市值 < 20 亿美元 | 规模与流动性偏弱 |
| `sharp` | `|ret_30d| ≥ 25%` | 近 30 日价格波动大 |
| `stale` | 快照超过 48 小时 | 数据可能过期 |

`risk_level`：无有效标签 = low；1–2 个 = medium；≥3 个 = high。`stale` 单独展示，不计入风险等级。

## 6. 数据完整度

8 个字段：`price`、`change_1d`、`ret_30d`、`market_cap_usd`、`pe`、`pb`、`roe`、`range`。

```text
coverage = 可用字段数 / 8
≥ 0.875 → high      (7–8 个)
≥ 0.625 → medium    (5–6 个)
< 0.625 → low       (≤4 个)
```

完整度衡量**字段是否齐全**，不代表数据准确。

## 7. 市场状态

对全部有 `ret_30d` 的公司：

```text
breadth    = 上涨家数 / 有效家数
median     = median(ret_30d)
dispersion = P75(ret_30d) - P25(ret_30d)
```

判定：

| 条件 | 状态 |
| --- | --- |
| breadth ≥ 0.60 且 median > 2% | 扩张 Expansion |
| breadth ≤ 0.40 且 median < −2% | 收缩 Contraction |
| 其他 | 中性 Neutral |

领先 / 落后环节 = 样本 ≥ 3 且中位涨幅最高 / 最低的环节。状态只描述当前结构，不预测方向。

## 8. 研究清单

| 清单 | 规则 | 排序 |
| --- | --- | --- |
| 质量优先 | `quality ≥ 70` 且 `valuation ≥ 50` | priority 降序 |
| 估值回落 | `valuation ≥ 70` 且 `quality ≥ 50` | valuation 降序 |
| 动能领先 | `momentum ≥ 80` 且 `ret_30d > 0` | momentum 降序 |

清单最多 8 家，只含有价格的公司。

## 9. 解读指南

- **分数是相对的**：同一公司在不同环节、不同日期，分数会变化。
- **高分不等于好公司**：可能只是估值低、动能强，或被归入样本较少的环节。
- **低分不等于差公司**：可能处于周期底部、数据缺失，或估值高但质量更强。
- **不要跨环节比较分数**：归一化在环节内完成。
- **结合完整度阅读**：完整度 low 的分数应视为参考。

## 10. 已知局限

1. 行情为延时或收盘价，不含盘口与盘中信号。
2. 静态 PE 对高增长公司不友好；亏损公司的估值因子缺失。
3. 缺少营收增速、订单、产能利用率与库存数据，质量因子只能依赖 ROE。
4. 52 周区间用 250 个交易日近似。
5. 汇率按日更新，跨币种比较存在日度误差。
6. 分类含编辑判断；公司业务会变化，需要季度复核。
7. 样本以大型上市公司为主，存在幸存者偏差。

## 11. 变更控制

1. 修改公式或阈值 → 更新本文件 + 站内方法页 + `CHANGELOG.md`，主版本号 +1。
2. 新增因子 → 先做离线对比，记录对清单的影响，再合并。
3. 修改样本或分类 → 在 PR 中列出公司、原因、影响页面。
4. 每次构建都会重新计算，不保留历史分数；如需回测，使用 `data/snapshots/` 中的历史快照。
