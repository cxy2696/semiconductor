# 製品：SiliconScope 半導体産業インテリジェンスデスク

バージョン 3.0 · 2026-11-11 · メンテナー：SiliconScope コントリビューター

## 1. ひとことで表すと

**世界の半導体バリューチェーンを、単一かつ公開され検証可能な視点で捉える。その構造、各企業の位置づけ、サイクルの状態、そして背景にある概念まで。**

SiliconScope は株価端末ではなく、銘柄選びのツールでもありません。これは**リサーチデスク**です。読者が 10〜30 分でひとつの工程またはひとつの企業について構造的な見方を組み立てられるようにし、その見方の背後にあるデータがどれだけ揃っているかを明らかにします。

## 2. なぜ存在するのか

半導体産業には次の 3 つの特徴があり、ひとつのツールだけでこの産業をカバーするのは困難です。

1. **知識の障壁が高い。** 製造装置、材料、プロセス、実装、メモリはそれぞれ固有の語彙を持ち、市場をまたいだ議論はすぐに意味を失います。
2. **周期性が強い。** 同じ指標でもサイクルの頂点と底では正反対の意味を持つことがあり、静的なバリュエーションはしばしば判断を誤らせます。
3. **地政学的なエクスポージャー。** 輸出管理、補助金、生産能力の国産化によって、企業の売上構成は短期間で変わり得ます。

無料で手に入る情報は、断片的なニュースか、単一の市場しか扱わない株価ページのどちらかです。読者に必要なのは**構造化された中間層**、すなわち価格を予測するのではなく、その工程がどうやって稼いでいるのか、誰が競争しているのか、いまどんな状態にあるのか、データは信頼できるのかを説明する層です。

## 3. 対象ユーザーとユースケース

| ユーザー | 典型的な目的 | サイトが提供するもの |
| --- | --- | --- |
| バリューチェーンを学ぶ学生・研究者 | 「面接やレポートの前に、製造装置・材料・ファウンドリ・実装がどうつながっているかを理解したい」 | バリューチェーンページ + 12 本の長編トピック + 4 言語の用語集 |
| 全体像を必要とするアナリスト・実務者 | 「工程別・地域別の主要プレイヤーとバリュエーションをひとつの表で見たい」 | 企業マップ + 工程統計 + バリュエーションと品質の散布図 |
| データ定義を重視する個人投資家 | 「このスコアはどこから来たのか。データはどれだけ欠けているのか」 | 手法ページ + データ充足度 + スナップショットの時点と出典 |

**明示的に対象外とするもの**：デイトレード、レバレッジやポジションの助言、目標株価、業績予想、ニュース全文の閲覧。

## 4. 対象範囲

### 対象

- **8 工程**：EDA / IP・設計サービス、チップ設計（ファブレス）、ウェハ製造（ファウンドリ / IDM）、メモリ、半導体製造装置、半導体材料、パッケージング＆テスト、モジュール・システム。
- **13 の本社地域**：中国本土、香港、台湾、米国、日本、韓国、オランダ、ドイツ、フランス、スイス、イギリス、イスラエル、タイ。
- **7 つの上場市場**：A 株、香港株、台湾株、米国株、日本株、韓国株、欧州株。
- **175 社の上場企業**。重複計上を避けるため、各社は主上場市場を 1 つだけ持ちます。
- **70 の製品タグ**。統制語彙から選ばれ、フィルタと企業ページの表示に使います。
- **52 の用語**。それぞれ英語・中国語・日本語・ドイツ語で定義を持ちます。
- **4 言語**：英語（デフォルト）、簡体字中国語、日本語、ドイツ語。

### 対象外

- 非上場企業（たとえば YMTC や SMIC の一部子会社）。
- 純粋な最終製品ブランドや販売代理店（売上の主軸が半導体である場合を除く）。
- 分足レベルの株価、注文板、オプション、デリバティブ。
- 企業ニュースの集約を超える深入りした報道。
- あらゆる種類の投資助言。

## 5. 情報アーキテクチャ

```text
/                          English home (default, x-default)
/zh/                       Chinese home
/ja/                       Japanese home
/de/                       German home
/companies.html            company map (filter / sort)
/companies/{id}.html       company page
/value-chain.html          value-chain panorama
/knowledge.html            knowledge index
/knowledge/{slug}.html     long-form topic
/glossary.html             glossary
/methodology.html          method and boundaries
/about.html                purpose, sources, licence, build information
/en/...                    legacy English URLs, redirecting to /
/zh/... /ja/... /de/...    localised mirrors with the same structure
/api/snapshot.{lang}.json  localised data snapshot (en, zh, ja, de)
/latest_data.json          legacy payload for the iOS client
```

コンテンツは 4 つの層で構成されます。

1. **事実**：株価、バリュエーション、時価総額、52 週レンジ、データ時点、出典。
2. **構造**：工程、ロール、地域、時価総額分布、集中度。
3. **判断**：研究優先度、リスクフラグ、市場状態、リサーチスクリーン。
4. **手法**：因子の定義、ウエイト、閾値、限界、免責事項。

判断の層は常に事実と手法までたどることができ、手法は常に公開されています。

## 6. 製品の中核ロジック

### 6.1 まず分類し、それから比較する

粗利率、資本集約度、サイクルのドライバーは工程ごとにまったく異なるため、工程をまたいで PER を比べても意味がありません。したがって、

- すべての因子は**その工程の中**でパーセンタイル正規化します。
- 企業数が 8 社未満の工程は全サンプルにフォールバックし、その旨を手法ページに明記します。
- ページには絶対値と相対スコアを併記し、「スコアが結論」となるのを避けます。

### 6.2 スコアは読む順序を決めるものであり、予測ではない

「研究優先度」が答えるのは「どの企業から読むべきか」であり、「どの企業を買うべきか」ではありません。

- スコアが高いというのは、現在公開されているデータにおいて、品質・バリュエーション・モメンタム・規模を総合した位置づけが相対的に強いという意味です。
- スコアが低いからといって悪い企業とは限りません。単に割高である、データが欠けている、サイクルの底にある、といった理由かもしれません。
- どのページにも「買い / 売り / 目標株価 / ポジションサイズ」は載せていません。

### 6.3 データ充足度を第一級の情報として扱う

すべてのレコードはデータ充足度スコア（8 項目のうち揃っている項目の割合）を持ち、すべてのページにデータ時点と出典を表示します。欠損項目は `—` と表示し、推測したり 0 で埋めたりはしません。取得に失敗した場合は前回のスナップショットを使い、ページに stale（データが古い）の印を付けます。

### 6.4 4 言語の等価性

英語・中国語・日本語・ドイツ語の各版は、ページ構造・データ・グラフが同一で、異なるのはインターフェースの文言とコンテンツの言語だけです。英語が正典ですが、英語版がより充実しているわけではなく、4 言語すべてが同じ情報を持ちます。いずれかの言語でコンテンツが欠けていると CI が失敗するため、「英語サイトが完全版で、他は要約」というよくある失敗を防げます。

## 7. 設計原則

1. **単一の真実の源**：企業マスタデータは `data/universe.csv` にのみ存在し、分類ラベルは `data/taxonomy.json` にのみ存在します。
2. **すべてをビルド時に**：ブラウザからサードパーティ API を呼ばず、CDN も使わず、グラフは SVG で描画します。
3. **検証可能**：すべての数値はスナップショットファイルとフィールド定義までたどれます。
4. **抑制の効いた視覚言語**：情報密度を最優先し、色は方向と分類のためにだけ使い、装飾的なアニメーションは使いません。
5. **印刷可能でアクセシブル**：セマンティックなテーブル、キーボード操作、WCAG AA のコントラスト、`prefers-reduced-motion` への対応。
6. **持続可能**：サーバーなし、データベースなし、有料 API なし。月次の維持コストはほぼゼロです。

## 9. リスクとコンプライアンス

- **データの遅延**：株価は遅延値または終値です。ページにその旨を明記し、取引判断には向かないものとしています。
- **データの誤り**：出典とスナップショットを公開し、訂正を受け付けます。絶対的な正確性は保証しません。
- **著作権**：ニュースはタイトル・出典・日付・リンクのみを保持します。ナレッジコンテンツは参考文献を明示した独自の解説です。
- **投資助言リスク**：すべてのページで「研究目的であり投資助言ではない」と繰り返し、手法ページには別途免責事項を掲載しています。
- **供給元への依存**：株価ソースは 1 つで、スナップショットへのフォールバックと検証済みのシンボルマッピングで緩和しています。ソースの追加はロードマップに記載しています。

## 10. バージョニングと進化

- セマンティックバージョニングを採用します。情報アーキテクチャや手法の変更はメジャー、機能追加やカバレッジ拡大はマイナー、データ訂正はパッチです。
- 手法を変更するときは、`documentation/METHODOLOGY_en.md` とその `_cn` / `_jp` / `_de` 訳、`data/i18n/*.json` の手法ページ文言、`CHANGELOG.md` を同時に更新し、プルリクエストに影響範囲を記載する必要があります。
- 現在の計画と運用モデルは [ROADMAP_jp.md](ROADMAP_jp.md) と [OPERATIONS_jp.md](OPERATIONS_jp.md) を参照してください。
